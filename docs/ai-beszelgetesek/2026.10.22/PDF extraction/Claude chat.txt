Here’s extract_pdf_text.py. Install the one dependency with pip install pypdf, then run it:

bash
python extract_pdf_text.py ~/Documents/pdfs              # one .txt per PDF, in pdfs/extracted_text/
python extract_pdf_text.py ~/Documents/pdfs -r           # include subfolders
python extract_pdf_text.py ~/Documents/pdfs -o out_dir   # choose the output folder
python extract_pdf_text.py ~/Documents/pdfs --combined all.txt   # everything in one file
Each output file marks where every page starts. If a PDF won’t open, the script reports it and carries on with the rest. At the end it lists any PDFs that came back with almost no text. Those are usually scanned images, and they need OCR instead of plain extraction. I can add OCR support if you have files like that.
