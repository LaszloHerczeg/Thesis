Where I didn't follow your brief exactly:

Framework: this platform only runs TanStack Start, so the app uses TanStack Router instead of a plain Vite + react-router setup. It runs entirely in the browser, and the pages live in src/pages as you asked.
Mocks: you asked for a separate mock version of each service. Instead, the switch happens inside src/api/http.ts, which sends requests either to the real server or to an in-browser fake server. That fake server has a handler file per area and enforces your error rules. So CSRF, error mapping and the 401/429 handling run the same way in both modes, and switching to FastAPI still only needs the two .env values. Say if you want literal per-service mock modules instead.
